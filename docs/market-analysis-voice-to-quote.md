## 三、市場空白地帶 (Gaps) 分析

### Gap 1: 紐西蘭本地化 — 完全空白

- **沒有任何一家** 專門針對紐西蘭市場的 voice-to-quote 工具
- 最接近的是澳洲工具 (VoiceQuoter, Flow-Through, JobJot)，但它們:
  - 使用 10% GST (NZ 為 15%)
  - 不支援 NZ 銀行帳號格式 (XX-XXXX-XXXXXXX-XX)
  - 不使用 NZ/British 拼寫慣例 (Labour, Organise, Centred)
  - 不整合 NZ 供應商 (Placemakers, Mitre 10, Bunnings NZ)
- **機會等級: 極高** — 市場完全未被服務

### Gap 2: 離線優先 (Offline-First) 做得不好

- 大多數宣稱 "Works Offline" 但實際上只是本地儲存草稿
- **Canterbury 農村地區** 的 tradies 需要完整的:
  - 離線錄音 → 本地 IndexedDB 暫存 → 上線自動同步
  - 離線時仍能瀏覽已存報價
  - "Download Audio" 作為安全備份
- 目前只有 G'dai Mate 和 Flow-Through 認真對待離線，但它們不是 NZ 市場
- **機會等級: 高**

### Gap 3: Kiwi 口音/俚語辨識

- 所有競爭者都使用通用 Whisper 或 Google STT，無特殊口音優化
- **完全沒有人** 針對 NZ 口音做:
  - Whisper vocabulary hints / prompt tuning
  - Kiwi 俚語解析 ("sweet as", "bucks", "grand", "mate", "arvo")
  - Maori 地名辨識 (Whangarei, Te Awamutu, Tauranga, Whakatane)
  - NZ trade 術語 (與 AU/UK 有細微差異)
- **機會等級: 高** — 直接影響核心使用體驗

### Gap 4: 會計軟體整合缺少 NZ 特定流程

- JobJot 和 VoiceQuoter 有 Xero 整合，但:
  - 不處理 NZ GST return 週期 (1/2/6 月)
  - 不符合 NZ IRD 稅務局的申報邏輯
  - 缺少 NZ 特定的 tax type 設定
- **機會等級: 中** (MVP 後期功能)

### Gap 5: Quote → Approval → Job 全流程 — 多數只做前半段

- 大多數工具止步於 "生成 PDF 並發送"
- **缺少完整流程**:
  1. 語音報價 → 2. 客戶線上核准 → 3. 自動轉工單 → 4. 完工記錄 → 5. 發票
- TraderInvoice 有 quote approval page，BizQuota 有 quote→job→invoice
- 但都不是 NZ 本地化的
- **機會等級: 中** (差異化機會，但 MVP 不需全部)

### Gap 6: 真正的 "Stupid Simple" 體驗 — 0 學習曲線

- 大多數工具仍需要: 註冊帳號 → 設定公司資訊 → 學習介面 → 才能開始
- 最接近零摩擦的:
  - **Mucka** (UK): "just send a voice note" 的對話式體驗
  - **VoiceQuoter**: Telegram bot (但 NZ tradies 不用 Telegram)
  - **Toolbot AI**: 免登入體驗
- **NZ 機會**: 用 SMS 或 WhatsApp 作為入口，NZ tradies 更熟悉
- **機會等級: 高** — 直接影響採用率

### Gap 7: 本地供應商價格整合

- **QuoteMate** (AU): 整合 Bunnings AU 即時價格 — 非常強大的差異化
- **Flow-Through** (AU): 整合 L&H / Middy's / Reece 批發商價格
- **Sleepless Tradesman** (UK): AI 材料價格查詢
- **NZ 完全空白**: 沒有任何工具整合:
  - Placemakers NZ
  - Mitre 10 NZ
  - Bunnings NZ
  - Trade-specific 供應商 (Mico, Ideal Electrical 等)
- **機會等級: 極高** — 巨大差異化，但技術難度也高 (需供應商 API 或爬蟲)

### Gap 8: 多語言/移民 Tradies 支援

- NZ 有大量移民 tradies (印度、菲律賓、太平洋島國、中國)
- BizQuota 在美國做了西語/烏克蘭語支援
- ezQuotePro 支援 30+ 語言錄音 → 英文輸出
- **NZ 市場完全空白**: 能用母語錄音 → 輸出英文 NZ 格式報價單
- **機會等級: 中高** — 殺手級功能但不是 MVP 必要

## 五、KSQ 五大核心優勢

### 優勢 1: 離線優先 — IndexedDB 暫存，真正的 0 訊號也能用

**市場現況**: 大多數競爭者宣稱 "Works Offline"，但實際上只是在離線時顯示錯誤訊息或儲存一個空草稿。Canterbury 農村、West Coast、Fiordland 等偏遠地區的 tradies 經常處於完全無訊號的環境中。

**KSQ 做法**:
- 使用 `idb-keyval` (IndexedDB) 在裝置端完整暫存錄音 Blob
- 離線錄音後立即顯示 "Draft saved locally" — UX 優先，不讓使用者等待
- 上線後自動嘗試 Groq Whisper API 轉錄；失敗則保留為 `pending_sync`
- "Sync All" 按鈕 + app 啟動時自動檢查
- "Download Audio" 安全備份選項，確保錄音永不遺失
- 最大 2 分鐘錄音 (約 20MB)，確保裝置穩定性

**競爭者對比**:
| 產品 | 離線能力 |
|------|----------|
| Flow-Through (AU) | PWA 離線，但依賴 Xero 同步 |
| G'dai Mate (AU) | 宣稱離線，細節不明 |
| FieldQuote | 本地儲存，無自動同步 |
| **KSQ** | **完整 IndexedDB 暫存 + 自動同步 + 音檔備份下載** |

---

### 優勢 2: 一鍵錄音，不需要學習任何介面

**市場現況**: 即使是最簡單的競爭者 (如 Mucka、VoiceQuoter) 仍需要使用者理解一個新的 app 介面、註冊流程、或學習特定的 bot 指令。NZ tradies 在工地上雙手沾滿泥土，沒有耐心學習任何新工具。

**KSQ 做法**:
- **一個巨大的錄音按鈕** — 打開 app 就看到，拇指可及
- Mobile-first, thumb-friendly 設計 — 所有按鈕至少 44x44px
- 觸覺回饋 (Vibration API) — 錄音開始/結束時震動提示
- 數字鍵盤自動觸發 — 價格欄位使用 `inputmode="decimal"`
- Sticky Footer — 主要操作 ("Send Quote") 永遠固定在底部
- **0 學習曲線**: 錄音 → AI 自動生成報價 → 一鍵發送

**競爭者對比**:
| 產品 | 上手難度 |
|------|----------|
| VoiceQuoter | 需學 Telegram bot + 設定 Google Sheets |
| Mucka | 對話式 AI，仍需理解指令 |
| Voice2Quote | 標準 app 介面，需註冊+設定 |
| **KSQ** | **打開即錄音，0 步驟上手** |

---

### 優勢 3: NZ 供應商價格整合 + Xero NZ

**市場現況**: 澳洲的 QuoteMate 整合了 Bunnings AU 即時價格，Flow-Through 整合了 L&H/Middy's/Reece。但 NZ 市場完全沒有對應產品整合本地供應商。

**KSQ 做法 (路線圖)**:
- **Phase 1 (MVP+)**: Xero NZ OAuth2 整合 — 報價自動同步為 Xero Draft Quote，含正確的 NZ GST tax type
- **Phase 2**: Placemakers NZ / Mitre 10 NZ / Bunnings NZ 價格查詢 — tradie 錄音提到材料時，自動匹配最新本地價格
- **Phase 3**: Trade-specific 供應商 — Mico (plumbing), Ideal Electrical, ITM 等

**競爭者對比**:
| 產品 | 供應商整合 | 會計整合 |
|------|-----------|----------|
| QuoteMate (AU) | Bunnings AU 即時價格 | ❌ |
| Flow-Through (AU) | L&H, Middy's, Reece | Xero (AU GST 10%) |
| JobJot (AU) | ❌ | Xero/MYOB/QuickBooks |
| **KSQ** | **Placemakers / Mitre 10 / Bunnings NZ** (路線圖) | **Xero NZ (15% GST)** |

---

### 優勢 4: Quote → Approval → Job 全流程

**市場現況**: 絕大多數 voice-to-quote 工具止步於 "生成 PDF 並發送"。tradie 發送報價後，後續的客戶核准、轉工單、完工、開發票仍需手動處理或切換到另一個工具。

**KSQ 做法**:
1. **語音報價** — tradie 在工地錄音，AI 生成結構化報價
2. **專屬報價頁面** — 生成公開 URL (ksq.nz/q/abc-123)，客戶可在手機上查看
3. **客戶線上核准** — 客戶在報價頁面一鍵 Accept / Request Changes / Decline
4. **自動轉工單** — 核准後自動建立 Job，追蹤進度
5. **一鍵開發票** — 完工後，報價內容自動帶入發票，同步至 Xero

**一條完整的鏈**: Voice → Quote → Customer Approval → Job → Invoice → Payment

**競爭者對比**:
| 產品 | 流程覆蓋範圍 |
|------|-------------|
| Voice2Quote | Voice → Quote → PDF (止步) |
| VoiceQuoter | Voice → Quote → Email/Xero Draft (止步) |
| TraderInvoice | Voice → Quote → Customer Approval → Invoice |
| BizQuota | Text/Voice → Quote → Approval → Job → Invoice |
| **KSQ** | **Voice → Quote → 公開 URL → Approval → Job → Invoice → Xero** |

### 優勢 5: 專門針對紐西蘭市場 — NZ 唯一

**市場現況**: 在我們研究的 15+ 個 voice-to-quote 工具中，**沒有任何一個**專門針對紐西蘭市場。最接近的是澳洲工具，但 AU 和 NZ 在稅務、拼寫、供應商、行業術語上有顯著差異。

**KSQ 的 NZ 本地化深度**:

| 維度 | KSQ 做法 | 競爭者 |
|------|----------|--------|
| **GST** | 15% NZ GST，支援 "GST Inclusive" / "Plus GST" 切換 | AU 用 10%, UK 用 20% VAT |
| **貨幣** | 預設 NZD ($) | 預設 CAD/USD/AUD/GBP/EUR |
| **拼寫** | NZ/British English — Labour, Organise, Centred | 美式拼寫或無特殊處理 |
| **日期** | DD/MM/YYYY | 混用各種格式 |
| **地址** | NZ Post 標準格式 | 無本地化 |
| **銀行帳號** | NZ 格式驗證 (XX-XXXX-XXXXXXX-XX) | 無 |
| **口音** | Whisper vocabulary hints 針對 Kiwi 口音 | 通用 STT |
| **俚語** | 解析 "grand", "bucks", "mate", "sweet as" | 無 |
| **Maori 地名** | Whangarei, Te Awamutu, Tauranga 等正確辨識 | 無 |
| **供應商** | Placemakers, Mitre 10, Bunnings NZ (路線圖) | AU/UK 供應商 |
| **稅務** | 未來可對接 IRD GST 申報週期 | 無 |

**這不只是語言翻譯，而是整個商業邏輯的在地化。**

## 六、戰略總結

### 核心護城河組合 (Moat Stack)

以上五大優勢形成一個 **互相強化的護城河組合**:

```
        ┌─────────────────────────────┐
        │   NZ 唯一 (優勢 5)          │  ← 市場定位
        │   15% GST / NZD / NZ 拼寫   │
        └──────────┬──────────────────┘
                   │
     ┌─────────────┼─────────────┐
     │             │             │
┌────▼────┐  ┌────▼────┐  ┌────▼────┐
│離線優先  │  │一鍵錄音  │  │供應商+   │  ← 核心體驗
│(優勢 1) │  │(優勢 2) │  │Xero 整合 │
│IndexedDB │  │0 學習曲線│  │(優勢 3) │
└────┬────┘  └────┬────┘  └────┬────┘
     │             │             │
     └─────────────┼─────────────┘
                   │
        ┌──────────▼──────────────┐
        │  全流程閉環 (優勢 4)     │  ← 商業價值
        │  Quote→Approval→Job→$   │
        └─────────────────────────┘
```

**任何單一優勢都可能被抄襲，但五個優勢的組合形成了一個難以複製的整體。**

### 為什麼現在是最佳時機

- 這個品類在 2025-2026 爆發式成長 (上述大多數公司成立於 2024-2025)
- AI 語音技術 (Whisper, GPT-4o-mini) 成本大幅降低
- **NZ 市場完全空白** — 沒有任何本地化的 voice-to-quote 工具
- 目前市場上 **沒有任何一個產品** 同時滿足以上 5 點
